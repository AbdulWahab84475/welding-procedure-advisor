# Welding Procedure Advisor

An AI-assisted welding procedure analysis application
built for mechanical engineering use.

## Technology

- Streamlit
- CrewAI
- Groq
- GPT-OSS 120B
- Python
- JSON engineering database

## Features

- Material analysis
- Thickness analysis
- Cast component assessment
- Welding purpose analysis
- Welding process analysis
- Consumable analysis
- Temperature considerations
- Inspection recommendations
- Welding sequence
- Risk identification
- Missing information detection
- Preliminary WPS-style summary
- Session memory

## Important

This application provides preliminary engineering guidance.

It does not replace:

- Qualified WPS/PQR
- Applicable welding codes
- Manufacturer datasheets
- Material specifications
- Qualified welding personnel
- Engineering approval

Numerical welding parameters should be verified
before production use.
